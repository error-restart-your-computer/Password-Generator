# Simple Password Generator

A beginner-friendly Python script that generates secure, random passwords based on user-defined length and character types.

## Features

- **Customizable Length**: Generate passwords of any length (default: 12 characters). 
- **Character Variety**: Includes uppercase letters, lowercase letters, digits, and special symbols.
- **Secure Generation**: Uses the `secrets` module for cryptographically strong random number generation.

## Installation

No external libraries are required. This script uses Python's built-in `secrets` and `string` modules.
